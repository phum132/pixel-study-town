# Pixel Study Town 🏘️📚

[English](README.md) | **ภาษาไทย**

เมืองพิกเซลน่ารักๆ ไว้เรียนด้วยกัน เดินเล่นกับเพื่อน คุยแชท แต่งห้องของตัวเอง จด To-do จับเวลาโฟกัสแบบ Pomodoro และเปิดเพลง lofi ฟังไปด้วย

> 🚧 กำลังพัฒนา ทำเสร็จแล้ว Phase 0–7 ที่เหลือคือห้องเรียน ระบบแรงค์ และเปิดให้ใช้งานจริง

## ฟีเจอร์

- 🏘️ **เมืองพิกเซล 4 ย่าน** (ห้องสมุด คาเฟ่ ย่านบ้าน สวนทะเลสาบ) เดินได้ทั้งคีย์บอร์ดและมือถือ (แตะค้างแล้วลาก)
- 👤 **สมัครสมาชิก + ตัวละคร** ล็อกอินด้วยอีเมล มีตัวละครพิกเซลให้เลือก 88 ตัว
- 👥 **ออนไลน์พร้อมกันหลายคน** เห็นเพื่อนเดิน แชทมีบับเบิลเหนือหัว และมีคอมมูให้เลือก 6 ห้อง
- 🏯 **ตึกสาธารณะ** (ห้องสมุด ห้องสมาธิ คาเฟ่ ร้านราเมน) คนในคอมมูเดียวกันเจอกัน ยืนบนเก้าอี้ได้เหมือนนั่งเรียนด้วยกัน
- 🏠 **บ้านส่วนตัว** วางเฟอร์นิเจอร์ เปลี่ยนลายพื้นและผนัง ไปส่องบ้านเพื่อนได้ หรือปิดบ้านไม่ให้ใครเข้าก็ได้
- 📝 **To-do** เลือกได้ทีละงานว่าจะให้คนที่มาส่องบ้านเห็นไหม
- ⏱️ **Pomodoro** โฟกัส 15/25/50 นาทีแล้วพัก ระหว่างโฟกัสจะขึ้น 📖 เหนือหัว
- 🎵 **เพลง lofi** มีสถานีไลฟ์สดจาก YouTube 6 สถานี หรือวางลิงก์เองก็ได้ ตั้งเพลงประจำบ้านให้เพื่อนกดฟังด้วยได้
- 🐍 **ตู้เกม Snake** ที่ลานกลางเมือง มีตาราง 10 อันดับ ฐานข้อมูลเล่นซ้ำทุกเกมเพื่อนับคะแนนเอง
- 📱 **หน้าจอมือถือ** มีแถบแท็บด้านล่าง (แชท / โฟกัส / งาน)

### ออกแบบมาให้โกงไม่ได้

อะไรก็ตามที่ใช้นับแรงค์ จะไม่เชื่อข้อมูลจากเบราว์เซอร์:

- เซิร์ฟเวอร์เกมตรวจความเร็วเดิน ถ้าวาร์ปจะไม่รับ
- ชื่อผู้เล่นดึงจากฐานข้อมูล ไม่ใช่ชื่อที่เบราว์เซอร์ส่งมา
- **คะแนน Snake ฐานข้อมูลนับเอง**: เบราว์เซอร์ส่งมาแค่การกดปุ่ม ฐานข้อมูลเล่นซ้ำจาก seed ของตัวเอง และเช็กว่าไม่ได้เล่นเร็วกว่าเวลาจริง
- **เวลาโฟกัสจับด้วยนาฬิกาของฐานข้อมูล** (`start_focus` / `finish_focus`) ต่อให้แก้นาฬิกาในคอมก็ไม่มีผล
- มีกฎ Row Level Security: แก้ได้เฉพาะโปรไฟล์ ห้อง และงานของตัวเอง ส่วน XP กับ coin ผู้เล่นแก้ไม่ได้เลย

## เครื่องมือที่ใช้

| ส่วน | เครื่องมือ |
|---|---|
| หน้าเว็บ | [Vite](https://vite.dev) + [React](https://react.dev) + TypeScript |
| เอนจินเกม | [Phaser 3](https://phaser.io) (แผนที่เมืองใช้รูปแบบไฟล์ของ [Tiled](https://www.mapeditor.org)) |
| ล็อกอิน + ฐานข้อมูล | [Supabase](https://supabase.com) (Postgres + Auth + Row Level Security) |
| เซิร์ฟเวอร์เรียลไทม์ | [Colyseus 0.16](https://colyseus.io) (Node.js) |
| เพลง | YouTube IFrame Player API |

## โครงสร้างโฟลเดอร์

```
client/                  หน้าเว็บ (สิ่งที่ผู้เล่นเห็น)
  src/game/              ฉาก Phaser: TownScene (เมือง), HomeScene (บ้าน), WorldScene (ส่วนที่ใช้ร่วมกัน), ตัวละคร
  src/ui/                หน้าจอ React: ล็อกอิน แต่งตัว แชท แต่งห้อง To-do นาฬิกา เพลง
  src/lib/               เชื่อมต่อ Supabase/Colyseus, รายการเฟอร์นิเจอร์, กฎการวางของ, ระบบจับเวลา
  public/assets/         ภาพ tile, แผนที่เมือง (town.json), LICENSES.md
  tools/make-town-map.mjs  สคริปต์สร้าง town.json (⚠️ จะเขียนทับถ้าแก้แผนที่ใน Tiled ไว้)
server/                  เซิร์ฟเวอร์เกม (การเดิน แชท บ้าน)
  src/rooms/             WorldRoom (ส่วนกลาง), TownRoom (เมือง), HomeRoom (บ้าน)
supabase/migrations/     ไฟล์ SQL สร้างตารางและกฎความปลอดภัยของฐานข้อมูล
```

## วิธีรันบนเครื่องตัวเอง

### 1. ติดตั้ง

- [Node.js](https://nodejs.org) เวอร์ชัน 22 ขึ้นไป
- ติดตั้งแพ็กเกจ:
  ```bash
  cd client && npm install
  cd ../server && npm install
  ```

### 2. ตั้งค่า Supabase

1. สมัครแล้วสร้างโปรเจกต์ฟรีที่ [supabase.com](https://supabase.com) (เลือก region **Singapore** จะใกล้ไทยที่สุด)
2. เปิด **SQL Editor → New query** แล้วรันไฟล์ในโฟลเดอร์ `supabase/migrations/` **ทีละไฟล์ตามลำดับ ไฟล์ละครั้งเดียว**:
   `001_profiles.sql` → `002_rooms.sql` → `003_todos_focus.sql` → `004_snake.sql` → `006_review_fixes.sql` → `007_math_adventure.sql` → `008_economy.sql`
   (`005_snake_fix.sql` ใช้เฉพาะฐานข้อมูลที่เคยรัน 004 เวอร์ชันแรกไปแล้ว)
3. ถ้าแค่ทดสอบในเครื่อง: ไปที่ **Authentication → Sign In / Providers → Email** แล้วปิด **Confirm email** จะได้สร้างบัญชีทดสอบได้โดยไม่ต้องใช้อีเมลจริง (ก่อนเปิดให้คนทั่วไปใช้ต้องเปิดกลับ)

### 3. สร้างไฟล์ `.env`

คัดลอกไฟล์ `.env.example` เป็น `.env` แล้วใส่ค่าที่ได้จาก **Project Settings → API Keys**:

- `client/.env` → `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`
- `server/.env` → `SUPABASE_URL`, `SUPABASE_KEY`

ให้ใช้คีย์ **publishable** (ขึ้นต้นด้วย `sb_publishable_...`) คีย์นี้อยู่ในหน้าเว็บได้ เพราะข้อมูลถูกป้องกันด้วยกฎของฐานข้อมูลอยู่แล้ว
⚠️ **ห้ามใส่คีย์ secret / service_role** ลงในไฟล์พวกนี้ และห้าม commit ขึ้น git

### 4. เปิดเซิร์ฟเวอร์ 2 ตัว (เปิด terminal 2 หน้าต่าง)

```bash
# หน้าต่างที่ 1: เซิร์ฟเวอร์เกม (port 2567)
cd server && npm run dev

# หน้าต่างที่ 2: หน้าเว็บ (port 5173) ใส่ --host แล้วมือถือที่ต่อ WiFi เดียวกันจะเข้าได้ด้วย
cd client && npm run dev -- --host
```

เปิดเบราว์เซอร์ไปที่ http://localhost:5173 ถ้าจะทดสอบแบบหลายคน ให้เปิดหน้าต่างไม่ระบุตัวตน (Incognito) แล้วล็อกอินบัญชีที่ 2
